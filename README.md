# Data Science Toolbox: Formative Sprint 0 (Data Review and Group Work Primer)

University of Bristol, Data Science Toolbox. Our group reviewed resources for doing data science in sports analytics. Each member analysed a different dataset.

## Project Group

* Luke D: Formula 1 tyre strategy (Python, FastF1)
* Thomas F: Premier League data (Python, penaltyblog)
* Morgan L: Premier League scoring and added time (R, tidyverse, BSDA)

This project has a 33/33/33 equity split between the three project members.

## Reading order and requirements

All report content is in the directory:

* report/

Each file is the work of the member named in its filename. The files can be read in any order, but this is the suggested order:

* 01-LukeD_F1_TyreStrategy.ipynb: does tyre make-up predict winning in 2022 dry races? (EDA, permutation tests, logistic and conditional logit models)
* 02-ThomasF_PremierLeague.ipynb: Premier League analysis
* MorganL/Rpremanalysis.Rmd (knitted output: MorganL/knittedpremanalysis.pdf): was the high-scoring 2023-24 Premier League season driven by longer added time and more goals after 90 minutes? Reproduces an existing analysis (replacing its z-test with Welch's t-test), extends it to cards and substitutions, relates the scoring change to Over 2.5 and BTTS betting markets, and extends to 2024-25 and 2025-26 using Football-Data match files with Bet365 odds

Executed notebooks with outputs are included for convenience, since the data download for the F1 notebook is rate-limited.
